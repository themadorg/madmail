Welcome to the Madmail blog. This is a place for project notes, updates, and practical guides for running your own chatmail relay.

Madmail is a Rust chatmail relay for Delta Chat. It brings SMTP, IMAP, encryption enforcement, and real-time services together in one binary.

If you are setting up a relay, start with [Quick Setup](/docs/quick-setup). For configuration and deployment details, browse the [documentation](/docs). You can also find the latest binaries and release notes on the [releases page](/releases).

Follow the [RSS feed](/blog/rss.xml) to keep up with new posts.
